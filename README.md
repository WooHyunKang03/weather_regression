# ASOS 108 풍속 예측

2023~2024년 ASOS 108 관측 자료로 1시간 뒤 풍속을 예측한 작업물이다.

## 구성

- `asos_108_2023_2024.csv`: 원본 관측 자료
- `wind_dataset.csv`: 시간 간격을 1시간으로 맞춘 학습·평가 데이터
- `wind_forecast.py`: 선형회귀 학습, 평가, 모델·예측·그래프 재생성 코드
- `saved_model/wind_linear_regression.json`: 학습된 회귀계수와 메타데이터
- `predictions.csv`: 2024년 12월 평가 결과
- `prediction_week.png`: 2024-12-01~2024-12-07 비교 그래프

## 실행

Python과 `matplotlib`이 필요하다.

```powershell
python -m pip install matplotlib
python wind_forecast.py
```

입력은 현재 풍속, 1시간 전 풍속, 2시간 전 풍속, 현재 기온, 현재 습도이며 정답은 정확히 1시간 뒤 실제 풍속이다. 학습은 정답 시각이 2023년 1월부터 2024년 11월까지인 행으로만 수행하고, 평가 중에는 재학습하지 않는다. 음수 회귀 예측은 0으로 자른다.

## 결과

- 학습: 16,720행
- 평가: 744행 (2024년 12월)
- 현재 풍속 유지 MAE: 0.653495 m/s
- 선형회귀 MAE: 0.594577 m/s
- 선형회귀는 기준보다 약 9.02% 낮은 MAE를 기록했다.

회귀 예측의 절대 오차가 큰 사례는 다음과 같다.

| 정답 시각(KST) | 실제 풍속 | 기준 예측 | 선형회귀 예측 | 선형회귀 절대 오차 |
|---|---:|---:|---:|---:|
| 2024-12-30 12:00 | 3.7 | 0.5 | 0.9480 | 2.7520 |
| 2024-12-18 23:00 | 0.7 | 3.8 | 3.3204 | 2.6204 |
| 2024-12-28 05:00 | 4.4 | 2.2 | 2.0379 | 2.3621 |
| 2024-12-26 04:00 | 4.0 | 1.6 | 1.6872 | 2.3128 |
| 2024-12-02 13:00 | 3.6 | 1.3 | 1.3558 | 2.2442 |

큰 오차는 풍속이 짧은 시간에 급격히 상승하거나 하락한 시점에 집중된다. 현재 및 직전 2시간 풍속만 사용하는 선형회귀는 이런 급격한 변화를 충분히 반영하지 못해 실제값과 예측값의 차이가 커진다.
